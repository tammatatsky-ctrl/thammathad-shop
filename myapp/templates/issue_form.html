{% comment %} issue_form.html — ฟอร์ม "แจ้งปัญหา" ของลูกค้า (ใช้ในหน้า /issue/) ใช้เมื่อ: มีปัญหากับออเดอร์หรือสินค้า (ของเสียหาย / ส่งผิด / ยอดไม่ตรง / ส่งล่าช้า) ผูกกับออเดอร์ได้ 2 ทาง: 1. มาจากปุ่มในหน้าติดตามออเดอร์หรือหน้าบัญชี (`/issue/?order=&phone=`) → `order` ถูกยืนยันสิทธิ์แล้วและฝังใน hidden input 2. เข้าหน้า `/issue/` โดยตรง → กรอกเลขออเดอร์ (ถ้ามี) คู่กับเบอร์โทรที่สั่งซื้อ ระบบจะตรวจ `_authed_order` ตอน POST จึงแจ้งแทนออเดอร์คนอื่นไม่ได้ คาดหวัง context: order (ไม่บังคับ), my_orders (รายการออเดอร์ของผู้ล็อกอิน), back_url, kinds การเลือกออเดอร์ — 3 กรณี (เรียงตามความสามารถของผู้ใช้) 1. `order` มาแล้ว (กดจากหน้าออเดอร์) → ซ่อน order_id/phone ไว้เลย 2. ล็อกอิน + มีออเดอร์ → **ให้เลือกจาก dropdown รายการของตัวเอง** (เรียงใหม่→เก่า พร้อมวันที่ ยอด และสถานะ) ไม่ต้องจำเลขออเดอร์แล้ว 3. ยังไม่ล็อกอิน → ต้องพิมพ์ "เลขออเดอร์ + เบอร์โทรที่สั่งซื้อ" เอง เพราะถ้าแสดงรายการออเดอร์ให้คนที่ยังไม่ล็อกอิน จะเป็นการเปิดเผย ออเดอร์ (และเบอร์โทร) ของลูกค้าทุกคนในร้าน หมายเหตุเรื่อง JS: dropdown ชื่อ `order_id` ตรง ๆ ไม่ใช้ hidden input ตอน POST จึงได้เลขออเดอร์ถูกต้องแม้ปิด JS ไว้ ส่วน JS มีหน้าที่เดียวคือ เติมเบอร์โทรให้ตรงกับออเดอร์ที่เลือก (ตอน POST `_authed_order` ยังตรวจ เบอร์ตรงกันเสมอ แม้เลือกจาก dropdown มาก็ไม่ได้ข้าม) {% endcomment %}
